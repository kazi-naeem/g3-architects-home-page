G3 Architects

A modern architect landing page built from scratch using HTML5 and CSS3. This is my second personal web development project, created to strengthen my front-end development skills and practice building structured, visually appealing websites.

About the Project

G3 Architects is a landing page concept for an architecture firm. It features a clean layout, warm colors, an orange accent theme, and multiple sections to present the firm's features, achievements, and sponsors.

Features

Navigation Bar — Home, About, Contact Us, and Login links.

Hero Section — Main heading, introduction, and Explore More button.

Image Gallery — A collection of images arranged in a grid.

Features Section — Highlights key features and design capabilities.

Experience Highlight — A dedicated section showcasing years of experience.

Facts & Statistics — Displays achievements and project statistics.

Sponsors Section — Sponsor logos with external website links.

Custom Styling — Warm background colors, orange accents, and typography.

Hover Effects — Interactive styling for buttons.

Technologies Used

HTML5

CSS3

Google Fonts — Work Sans
